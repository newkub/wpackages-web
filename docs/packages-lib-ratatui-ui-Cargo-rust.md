## Quick Start

### Build

```bash
cargo build -p ratatui-ui
```

### Test

```bash
cargo test -p ratatui-ui
```

### Run

```bash
cargo run -p ratatui-ui
```

### Lint

```bash
cargo clippy -p ratatui-ui
```

### Documentation

```bash
cargo doc -p ratatui-ui --no-deps
```
